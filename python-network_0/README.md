# Python - Network #0

HTTP basics with `curl`: methods, headers, bodies and status codes.

| File | Description |
|------|-------------|
| 0-body_size.sh | Size in bytes of the response body |
| 1-body.sh | Body of a 200 response |
| 2-delete.sh | Body of a DELETE request |
| 3-methods.sh | HTTP methods accepted by a server |
| 4-header.sh | GET with header `X-HolbertonSchool-User-Id: 98` |
| 5-post_params.sh | POST with `email` and `subject` |
| 100-status_code.sh | Status code only |
| 101-post_json.sh | POST a JSON file |
| 102-catch_me.sh | Request that makes the server answer "You got me!" |
