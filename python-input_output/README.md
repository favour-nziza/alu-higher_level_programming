# Python - Input/Output

Reading and writing files with `with`, and serializing objects to JSON.

| File | Description |
|------|-------------|
| 0-read_file.py | `read_file(filename)` prints a UTF8 text file |
| 1-write_file.py | `write_file(filename, text)` writes and returns the char count |
| 2-append_write.py | `append_write(filename, text)` appends and returns the char count |
| 3-to_json_string.py | Object -> JSON string |
| 4-from_json_string.py | JSON string -> object |
| 5-save_to_json_file.py | Save an object to a file as JSON |
| 6-load_from_json_file.py | Load an object from a JSON file |
| 7-add_item.py | Script adding its arguments to a list saved in `add_item.json` |
| 8-class_to_json.py | Dictionary description of an object for JSON |
| 9-student.py | `Student` with `to_json()` |
| 10-student.py | `to_json(attrs=None)` with attribute filter |
| 11-student.py | Adds `reload_from_json(json)` |
| 12-pascal_triangle.py | `pascal_triangle(n)` returns Pascal's triangle |
